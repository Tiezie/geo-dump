# geosite-dump 与 geoip-dump 使用说明

整理日期：2026-09-30。依据本文件夹中的脚本源码及 VPS 实际帮助信息编写。

## 1. 两个工具做什么

| 工具 | 用途 | VPS 脚本位置 | 默认数据文件 |
|---|---|---|---|
| geosite-dump | 查看分类、搜索域名规则文本 | /usr/local/bin/geosite-dump | /usr/local/share/xray/geosite.dat |
| geoip-dump | 查看 IP 网段、查询 IP 所属分类 | /usr/local/bin/geoip-dump | /usr/local/share/xray/geoip.dat |

它们是纯 Python 3 脚本，没有第三方 Python 库依赖。工具读取数据文件进行查询，不修改数据文件或 Xray 配置，也不自动下载或更新数据库。

本文件夹目前保存的是两个脚本，未包含 geosite.dat 和 geoip.dat。在 VPS 上可以使用现有数据库；在本地运行则需要另行准备数据库。

## 2. 在 VPS 上使用（最方便）

从本地终端连接：

```powershell
ssh your-vps
```

登录后运行：

```bash
geosite-dump info
geoip-dump info
geosite-dump --help
geoip-dump --help
```

如果提示找不到命令，使用绝对路径，例如：

```bash
python3 /usr/local/bin/geosite-dump info
python3 /usr/local/bin/geoip-dump info
```

也可以不进入交互式 SSH，直接从本地执行：

```powershell
ssh your-vps "geosite-dump search openai"
ssh your-vps "geoip-dump lookup 8.8.8.8 -v"
```

## 3. geosite-dump：域名规则

基本格式：`geosite-dump [-f 数据文件] 子命令 [参数]`。

| 命令示例 | 功能 |
|---|---|
| `geosite-dump info` | 显示实际读取的文件和统计 |
| `geosite-dump list` | 列出所有分类，默认按名称排序 |
| `geosite-dump list --sort count` | 按规则数量排序 |
| `geosite-dump list --filter google` | 筛选名称含 google 的分类 |
| `geosite-dump list -q` | 只输出分类名称 |
| `geosite-dump show google` | 显示 google 分类的规则 |
| `geosite-dump show 'google@cn'` | 显示 google 分类中带 cn 属性的规则 |
| `geosite-dump names google` | 搜索分类名称 |
| `geosite-dump search openai` | 搜索所有分类中的规则文本 |
| `geosite-dump common ai google` | 找出同时有 ai 和 google 匹配结果的分类 |
| `geosite-dump same ai google` | 找出同一条规则文本同时匹配 ai 和 google 的结果 |

示例分类和属性是否存在，取决于你使用的数据文件。`common` 和 `same` 至少需要两个关键词：`common` 允许两个关键词命中同一分类中的不同规则；`same` 要求它们命中同一条规则。

### 搜索模式

默认按包含关系搜索，不区分大小写。`names`、`search`、`common`、`same` 支持下列互斥模式，每次只能选择一个：

| 参数 | 含义 | 示例 |
|---|---|---|
| `-x` / `--exact` | 整个分类名或规则文本精确匹配 | `geosite-dump search openai.com -x` |
| `-w` / `--word` | 以非英文字母、非数字作为边界匹配 | `geosite-dump search ai -w` |
| `-r` / `--regex` | 使用正则表达式搜索文本 | `geosite-dump search '(^|[.-])ai([.-]|$)' -r` |

例如搜索 `ai -w`，可以命中 `example.ai`、`ai.google`、`test-ai.com`，不会因为包含 ai 就命中 `mail.google` 或 `openai.com`。

`search` 搜索的是数据库保存的规则文本，不是判断某个域名是否会被 Xray 的全部路由规则匹配。`-r` 使用你提供的正则搜索文本，也不是执行数据库中保存的正则规则来判定域名。

### 规则类型及输出选项

`show`、`search`、`common`、`same` 支持 `-t` / `--type`，可以重复指定：

```bash
geosite-dump show google -t domain
geosite-dump search openai -t domain -t full
geosite-dump search openai -q
geosite-dump show google --no-summary
```

| 类型 | 规则含义 |
|---|---|
| keyword | 域名关键词 |
| regexp | 正则规则 |
| domain | 域名及其子域名 |
| full | 完整域名 |

`-q` 在搜索命令中只输出命中的分类名；`--no-summary` 隐藏统计。`show` 不支持 `-q`。查看具体子命令参数可执行 `geosite-dump search --help` 等。

## 4. geoip-dump：IP 和网段

基本格式：`geoip-dump [-f 数据文件] 子命令 [参数]`。

| 命令示例 | 功能 |
|---|---|
| `geoip-dump info` | 显示文件及分类、网段等统计 |
| `geoip-dump list` | 列出所有分类 |
| `geoip-dump list --sort count` | 按网段数量排序 |
| `geoip-dump list --filter cn` | 筛选名称含 cn 的分类 |
| `geoip-dump list -q` | 只输出分类名称 |
| `geoip-dump show cn` | 显示 cn 分类保存的 CIDR 网段 |
| `geoip-dump show cn --ipv4` | 只显示 IPv4 网段 |
| `geoip-dump show cn --ipv6` | 只显示 IPv6 网段 |
| `geoip-dump search cn -x` | 精确搜索分类名 cn |
| `geoip-dump search '^(cn|us)$' -r` | 使用正则搜索分类名 |
| `geoip-dump lookup 8.8.8.8` | 查询 IP 命中哪些分类 |
| `geoip-dump lookup 8.8.8.8 -v` | 同时显示具体命中网段等详情 |
| `geoip-dump lookup 2001:4860:4860::8888` | 查询 IPv6 地址 |
| `geoip-dump lookup 8.8.8.8 -q` | 只输出命中的分类名 |
| `geoip-dump contains cn 223.5.5.5` | 判断指定 IP 是否属于 cn 分类 |
| `geoip-dump contains private 192.168.1.1` | 判断 IP 是否属于 private 分类 |

`geoip-dump search` 搜索分类名称；查询 IP 要使用 `lookup` 或 `contains`，不能把 `search` 当作 IP 查询。

`--ipv4` 与 `--ipv6` 互斥。`show`、`search`、`lookup` 支持 `--no-summary`；`search` 支持 `-x`、`-r`（互斥），不支持 `-w`。

`contains` 输出 YES 或 NO。两种正常结果都不会通过不同退出码区分，因此自动化时不能仅用命令成功与否判断 IP 是否属于分类。

对于 `reverse_match: true` 的分类，保存的是排除网段；工具会反转包含判断。此时 `show` 展示的网段不等于最终匹配的 IP 集合。

所有查询结果以所读取的数据库为准，不代表实时 IP 地理位置或最终 Xray 路由结果。

## 5. 指定其他数据库

全局参数 `-f` 必须放在子命令前面：

```bash
geosite-dump -f /path/geosite.dat search openai
geoip-dump -f /path/geoip.dat lookup 8.8.8.8
```

## 6. 在本地 Windows 上运行

安装可用的 Python 3 后，在 PowerShell 中进入本文件夹。脚本没有 `.py` 后缀，也可以交给 Python 运行：

```powershell
cd 'C:\path\to\geo-dump'
py -3 .\geosite-dump --help
py -3 .\geoip-dump --help
```

如果系统使用 `python` 命令，可将 `py -3` 替换为 `python`。

要在本地查数据库，可从 VPS 下载数据文件到当前目录（需要联网；本说明编写时尚未下载）：

```powershell
scp your-vps:/usr/local/share/xray/geosite.dat .\geosite.dat
scp your-vps:/usr/local/share/xray/geoip.dat .\geoip.dat
py -3 .\geosite-dump -f .\geosite.dat info
py -3 .\geosite-dump -f .\geosite.dat search openai
py -3 .\geoip-dump -f .\geoip.dat lookup 8.8.8.8 -v
```

Windows 上需要显式提供 `-f`，因为默认路径是 VPS 的 Linux 路径。下载的数据文件是当时的快照，后续不会自动与 VPS 同步。

## 7. 分页、导出及常见问题

VPS 上分页和导出：

```bash
geosite-dump show google | less
geoip-dump show cn --ipv4 | less
geosite-dump search openai --no-summary > openai-rules.txt
geoip-dump show cn --ipv4 --no-summary > cn-ipv4.txt
```

使用 `less` 时按 `q` 退出；重定向 `>` 会覆盖同名输出文件。

| 现象 | 处理方式 |
|---|---|
| 找不到数据文件 | 使用 `info` 核对路径，用 `-f` 指向实际数据库 |
| 找不到分类 | 使用 `list` 或分类名搜索；不同数据源包含的分类可能不同 |
| 搜索 ai 结果太多 | 尝试 `-w`、`-x` 或更具体的关键词 |
| 正则表达式无效 | 检查正则语法，并给表达式加引号 |
| 数据解析报错 | 核对是否为对应的 Xray geosite/geoip 数据文件，确认文件下载完整 |
| 本地无法运行 py/python | 检查 Python 3 是否安装、命令是否加入 PATH |
